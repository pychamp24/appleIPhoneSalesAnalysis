# appleIPhoneSalesAnalysis
in this project, I conducted an end-to-end analysis of iPhone product data using Python's data science ecosystem. Starting from raw data (apple_products.csv), I performed systematic data cleaning, exploratory data analysis (EDA), and visualization to uncover valuable insights into Apple's product sales and pricing strategies.
Key questions such as product pricing trends, rating distributions, and feature comparisons were addressed through clear, well-structured analysis.

Key Skills Demonstrated:

Data Handling: Imported and processed real-world CSV data using Pandas.

Data Cleaning: Managed missing values and inconsistent entries to prepare clean datasets for analysis.

Exploratory Data Analysis (EDA): Used descriptive statistics and group-wise analysis to summarize key features of the dataset.

Data Visualization: Created impactful plots (bar plots, scatter plots) using Matplotlib and Seaborn to present trends and relationships.

Business Insights: Interpreted the data to suggest potential pricing and product feature strategies.

Jupyter Notebook Skills: Structured the analysis in a clean, readable, and reproducible format using Markdown and code cells.

Developed a strong understanding of how to clean and prepare real-world sales data.
